You do not have to adopt all of it

Try one chapter

Assign a single module as a supplement alongside whatever you use now. One class period of setup, and it costs your students nothing.

Take just the ancillaries

Use the slide decks and the test bank even if you keep your current textbook. Both are editable and licensed for reuse.

Replace the textbook

Assign all eighteen chapters. Every student has the full course material before the first class meeting, at no cost.

Putting a chapter in Canvas

  1. Copy the chapter link. Open the module index and copy the URL for the chapter you want.
  2. Create an Assignment. Paste the link into the description. Set the submission type to file upload, since students submit a Completion Report PDF.
  3. Set the point value to whatever the assignment it replaces was worth. Chapters run roughly 1,000 to 1,900 points internally and report a letter grade and percentage, so you can map the percentage onto any scale you use.
  4. Tell students to submit the PDF, not a screenshot. Only the PDF carries the integrity code that lets you verify the work.
  5. Import the question bank if you want a quiz: Settings → Import Course Content → QTI .zip file. The bank lands under Quizzes → Manage Question Banks.

Two things worth knowing before you assign it

Progress is session-based

Students should finish a chapter in one sitting of about 45 to 60 minutes. If they close the tab, progress may be lost. Say this explicitly in your assignment description. It is the single most common source of student email.

Reflections are real writing

Each section asks for at least 50 words in the student's own words, and the full text lands in the Completion Report. That makes the report usable as direct evidence for Critical Thinking and Communication assessment, not just participation credit.

Contested topics get both sides

Abortion, voting law, immigration, affirmative action, religious displays, and sex and gender all appear, each with the strongest argument on every side stated in parallel. The speaker notes tell instructors not to share their own view.

Accessibility

Every scored activity is operable by keyboard and exposed to assistive technology. Reveal cards and quiz options carry proper roles and states, feedback is announced through live regions, focus indicators are visible, and every image has descriptive alternative text. This is verified by an automated test that simulates a keyboard-only student earning points, rather than by inspection. Current status and remaining gaps are documented in ACCESSIBILITY.md.

What it does not do yet

Anyone evaluating a resource deserves the limits along with the pitch:

  • There is no printed edition. Everything is browser-based, which suits students with phones and inconveniences students who want paper.
  • Screen-reader testing so far is automated. Verification with JAWS, NVDA, or VoiceOver by an actual screen-reader user is still outstanding.
  • Slide decks are still being released chapter by chapter.
  • Texas law changes every session, so some content will be a session behind until the next review pass. Where litigation is live, the slides tell you to verify status before teaching.
